# Pulsar VPN

A fast, free VPN for Windows. One tap connects you to the fastest free server for gaming or speed —
no account, no ads, no registration.

**[Download PulsarVPN.exe](../../releases/latest/download/PulsarVPN.exe)** · Windows 10 & 11

Pulsar connects to free networks run by Cloudflare (WARP), the non-profit Riseup, and the
VPN Gate academic project, and picks the quickest one from your own connection.
